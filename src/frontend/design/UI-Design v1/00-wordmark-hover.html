DocuMate 字标 · hover 触发动效对比

5 个方向, 每个一张卡片. 鼠标移到字标上感受效果, 移开就恢复.

⚠️ 注意: 入场动效已经完成 (页面加载时只播一次), 然后才是 hover. 等字标稳定后再 hover.

Hover A 通用质感
o c u M a t e
效果: 字标整体抬起 6px + 加深投影. 像被指尖轻轻托起.
质感: 干净 / 安全 / 通用. 跟按钮 hover 一个套路.
风险: 太"标准", 没记忆点.
Hover B 推荐
o c u M a t e
效果: D 内部书翻页加速 (4s → 1.3s) + 翻起角度 -22° → -55° (翻得更夸张).
质感: 跟"文档助手"主题强绑定. 鼠标移上去像有人在加速翻你的书.
优势: 独有 / 别人抄不走 / 视觉惊喜.
Hover C 灵动派
o c u M a t e
效果: 每个字母独立左右摇晃 (rotate -3°/+3°) + 微抬起 2px, stagger 60ms 像波浪.
质感: 灵动 / 调皮 / 像在跟你打招呼.
风险: 可能跟"严肃文档" 调性冲突, 像玩具.
Hover D 高级感 / Linear 派
o c u M a t e
效果: 一个柔光圆跟着鼠标在卡片上移动, 像一个 spotlight 在追你.
质感: 高级 / Linear / Vercel 派. 在鼠标周围出现 180px 的浅色光晕.
缺点: 需要 JavaScript 跟踪鼠标位置.
Hover E 浪漫派
o c u M a t e
效果: e 旁的 sparkle 放大 1.6×, 同时周围多冒出 3 颗小 sparkle (不同颜色 + 旋转角度).
质感: 浪漫 / 庆祝感 / 像在欢迎你.
风险: 偏装饰, 可能稍 cute, 跟"专业工具" 调性有距离.
推荐组合 B + A 轻版
o c u M a t e
组合配方:
① 字标整体抬起 4px + 投影 (轻版 A, 不过冲)
② D 内部翻书加速 (B, 4s → 1.5s + 翻起角度更大)
③ Sparkle 微微放大 1.25×
效果: 既有通用质感 (lift), 又有 DocuMate 独有的"翻阅" 感, 还有 sparkle 点缀.
这是我的推荐: 不抢戏, 但有性格.
📋 你需要做的

1. 鼠标依次放上 5 张卡 + 推荐组合, 感受不同 hover 效果

2. 跟我说你最喜欢的 (单选 / 多选 / 自己组合)

3. 比如: "B 太单一加上 A 的抬起" / "用 D 就够了, 别的都不要" / "B + E 一起来个浪漫"

💡 我的偏好顺序
  1. 推荐组合 (B + A 轻版): 不抢戏 + DocuMate 独有 + 通用质感
  2. B 单独: 极简版, 只动 D 内的书, 其他保持静态. 最克制
  3. D 磁吸光晕: 现代高级派, 但跟 DocuMate 主题关联弱
  4. A 单独: 太通用, 跟随便哪个按钮 hover 一样
  5. C 摇晃 / E 爆发: 偏装饰, 可能跟"严肃工具" 调性冲突, 慎用
